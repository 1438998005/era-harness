# era harness

**eraTW / Emuera 脚本工程的本地 AI 开发助手。**

这不是又一个通用编程助手。它把日式脚本工程里最容易出事的那几件事——**编码、日志、指令语义、加载验证、改动边界**——做成插件自己的一等约束，而不是指望模型「注意一下」。每一步写盘都先出 diff，你点了才落盘。

配套的核心库位于 `packages/era-harness-core/`（日志解析、工程画像、编码安全读取、指令数据），零运行时依赖；它在**构建期**被 esbuild 内联进扩展产物，因此不进入分发包。

---

## 它解决什么问题

eraTW 一类工程的源码是 CP932 的 `.ERB` / `.CSV`，混着全角符号、特殊转义和几十万行口上文本。通用 AI 编辑器在这里会稳定翻车：

| 通用编辑器的默认行为 | 后果 |
| --- | --- |
| 按 UTF-8 写回 | 整份文件乱码 |
| 大文件整段替换 | 行尾与编码漂移 |
| 只看单个文件 | 改了口上却漏了引用表 |
| 自动执行一切 | 一条命令把工程洗了 |
| 改完不验证 | 语法错了也以为生效了 |

era harness 针对每一条都给了具体机制，而不是提示词劝告。

## 当前能力

### 读懂工程

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 编码安全**读取**（BOM 探测 + CP932 解码） | 可用 | 日志/脚本自动识别编码；大文件按行边界限流，不会把宿主卡死 |
| 工程画像（路径无关） | 可用 | 自动探测脚本目录、口上目录、备份目录、引擎 exe，不写死任何目录名 |
| Emuera 日志诊断 | 可用 | 解析引擎日志，按种类归类语法错误并给出修法 |
| 指令手册查询 | 可用 | 内置 **312 页 / 2000+ 名字**离线快照；有网时整页替换为上游最新版，并明确标注来源 |
| 脚本符号检索 | 可用 | 按标签/调用点检索，自动排除注释与备份目录里的假标签 |

### 改动与验证

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 会话读写闭环 | 可用 | 每个改动先生成 diff → 审批 → 落盘 |
| 身份分区 | 可用 | 本体侧 / 口上·剧本侧 / 权限全开，按身份限制作业范围；越界即使开了自动批准也会停下来问你 |
| ERB 结构体检 | 可用 | 检测 IF/FOR/SELECTCASE 等块与括号是否因本次改动而变得不配平 |
| 真实启动引擎验加载 | 可用 | 启动真实引擎、等待静止，报告「加载痕迹」（懒加载索引是否重建、存档是否更新）与本次新写入的日志 |
| 更新 eraTW | 可用 | 拉取社区版差异 → 生成计划 → 弹窗确认 → 备份后落盘，可一键撤销 |
| 内置知识检索 | 可用 | 编码纪律 / 导入合并闸门 G1–G8 / 口上结构契约 / 存档迁移判据，每条附「症状→根因→修法」反模式；可离线 |

### 底座

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 模型提供方 | 可用 | 免费池（自动在多个免费通道间 failover）、DeepSeek、任意 OpenAI 兼容端点 |
| MCP 接入 | 可用 | stdio / SSE / HTTP，仅本地配置 |
| Skill 加载 | 可用 | 扫描工作区内的 `SKILL.md`，无远端技能源 |

## 安装（仅本地）

本插件**不进入任何在线分发渠道**，只做本地 sideload：

```bash
code --install-extension era-harness-3.88.0.vsix
```

或在编辑器里 `Ctrl+Shift+P` → `Extensions: Install from VSIX...`。装完重载窗口。

首次启动即用：无需登录、无需账号。API Key 如需填写，只存在本机。

## 设计取向

1. **减法优先。** 上游的账号体系、遥测、特性开关、插件市场、远端配置轮询全部移除，保留「本地能跑起来的最小闭环」。没有网络回调，没有静默上报。
2. **改动可审。** 任何写盘前都能看到 diff；批量替换有范围提示；越界修改必须人工点头。
3. **判据优先于措辞。** 「加载成功」不看模型怎么说，看引擎产物有没有变化；「来源是新的」不靠猜，返回值里带 `在线` / `内置快照` 标注。
4. **路径无关。** 不预设 `ERB/`、`口上/` 这类目录名。工作区结构是每个创作者自己搭的，插件靠文件扩展名与引擎产物去认，认不出就退回保守行为。

## 已知限制

- **日志不能当加载判据。** Emuera 停在标题画面时不写游戏日志。`run_game` 报告「日志没变」不代表失败，请看同一节里的「加载痕迹」。
- **`lazyloading.bin` 只在 ERB 有改动时才重建。** 没改脚本就跑验证，本就不会有重建痕迹。
- **强制结束不保存进度。** `run_game` 默认在报告完成后关闭引擎，用的是进程终止，不经引擎的关闭流程。
- **在线指令正文依赖上游仓库。** 取不到时自动退回内置快照，并在结果里说明原因；可用 `ERA_HARNESS_REFERENCE_ONLINE=off` 完全禁网。

```

webview-ui/                   侧栏界面（React + Vite）
assets/icons/                 图标
```

## 构建

```bash
npm install                                 # 插件依赖
npm run protos                              # 生成 proto 客户端
npm run package                             # 类型检查 + webview 构建 + lint + 打包 dist
npx vsce package --no-dependencies --allow-missing-repository

# 只跑核心库测试时需要它自己的依赖
cd packages/era-harness-core
npm install
npm test
```
